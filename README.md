# Estimating-the-amount-of-data-to-archive-frontendСтраницы приложения

По заданию для гостя доступны 2 страницы просмотра и нижнее меню:

1. Страница «Плитка» (каталог алгоритмов)

Витрина карточек с фильтром:

- Поле фильтра (ползунок Form.Range): позволяет отфильтровать алгоритмы по минимальной степени сжатия (от 1.0x до 5.0x). Рядом выводится выбранное число.
- Карточки алгоритмов (Card):
- Картинка алгоритма (если в моке поле image_url: null или ссылка сломалась, отображается дефолтная картинка из проекта /default-algorithm.png).
- Бейдж со степенью сжатия (например, 3.2x).
- Название и краткое описание алгоритма.
- Текст со скоростью работы в МБ/с и счетчик лайков.

2. Страница «Лента» (просмотр карточки с видео)

Полноэкранный плеер для поочередного изучения алгоритмов:

- Плеер <video>: проигрывает видео работы алгоритма (если video_url: null, играет дефолтное видео /default-algorithm.mp4).
- Название и описание: плашки поверх видео с именем алгоритма и подробным текстом.
- Показатель скорости: строка со скоростью компрессии.
- Кнопка «Следующий →»: по клику переключает на следующий алгоритм из списка моков по кругу.

3. Нижнее меню (Navbar)

Закреплено внизу страницы, содержит 4 пункта:

- Лента — активна, открывает страницу с видео.
- Плитка — активна, открывает каталог с карточками и ползунком.
- Добавление — заблокирована (disabled), нельзя нажать.
- Войти (справа) — заблокирована (disabled), нельзя нажать.
