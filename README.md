# Клиентское веб-приложение (SPA) для каталогизации и оценки алгоритмов сжатия данных

---

## Описание страниц приложения

### 1. Каталог алгоритмов сжатия — Плитка (`CatalogPage.tsx`)
Главная страница приложения, доступная как гостю, так и авторизованному пользователю:
* **Панель фильтрации (`FilterBar`):** интерактивный ползунок выбора минимального коэффициента сжатия (`от 1.0x до 5.0x`) с кнопкой применения поиска «Найти». Значение фильтра сохраняется в глобальном состоянии Redux (`filterSlice`) при переходах между страницами.
* **Двухколоночная сетка карточек (`AlgorithmCard`):** отображает обложку алгоритма, бейдж со степенью сжатия (`x`), название, краткое описание, скорость компрессии (`МБ/с`) и счётчик лайков.
* **Интерактивность:** нажатие на карточку открывает выбранный алгоритм в режиме видеоленты; для создателя карточки (`is_creator === 1`) доступна кнопка логического удаления записи.

### 2. Интерактивная видеолента (`FeedPage.tsx`)
Полноэкранный режим демонстрации работы алгоритмов компрессии (в формате вертикальных карточек):
* **Видеоплеер:** автоматическое цикличное воспроизведение демонстрационного видеоролика процесса сжатия из хранилища MinIO (или локальных ассетов).
* **Информационные виджеты:** отображение показателей коэффициента сжатия (`⚡`), скорости обработки (`🚀 МБ/с`), счётчика лайков (`❤️`) и кнопки перехода к следующему алгоритму (`➜ След.`), учитывающей текущий фильтр из каталога.
* **Разворачиваемое описание:** текстовый блок в нижней части экрана с кнопкой «Еще / Скрыть» для чтения полного описания принципа работы алгоритма.
* **Оценка публикаций:** установка и снятие отметки «Нравится» доступна исключительно авторизованному пользователю.

### 3. Создание и публикация алгоритма (`AddAlgorithmPage.tsx`)
Двухшаговый мастер добавления нового алгоритма сжатия (доступен только после входа в систему):
* **Шаг 1 — Создание черновика:** загрузка демонстрационного видеоролика и изображения карточки с предпросмотром, а также ввод наименования алгоритма. При нажатии «Далее» формируется черновик (`status = "draft"`), в котором поля публикации (`algorithm_description`, `compression_ratio`, `compression_speed_mbps`, `configured_at`) остаются пустыми (`NULL`).
* **Шаг 2 — Публикация характеристик:** отображение выбранных медиафайлов и заполнение тематических параметров компрессии (коэффициент сжатия, скорость в МБ/с и развёрнутое описание). По нажатию «Опубликовать» запись переводится в статус `published` и отображается в общем каталоге.

### 4. Аутентификация и регистрация (`AuthPage.tsx`)
Страница управления доступом к системе:
* **Два режима работы:** переключение между формой входа в существующий аккаунт («Вход в систему») и формой создания новой учётной записи («Регистрация»).
* **Управление сессией:** отправка учётных данных на сервер (`POST /api/login` / `POST /api/register`), сохранение сессионной HTTP-cookie и обновление состояния авторизации в Redux (`authSlice`).
* **Навигационная панель (`NavigationBar`):** фиксированное нижнее меню на всех страницах («Лента», «Плитка», «Добавление», «Войти / Выход»). При нажатии «Выход» сессия завершается, а фильтр каталога сбрасывается к исходному значению `1.0x`.
